# 🌐 Host Koda on GitHub Pages (`gitofr8-source.github.io/Koda-Free`)

Your repository is configured for **GitHub Pages** with `.nojekyll` support, clean `404.html` routing, relative paths, and client-side static auth fallback.

---

## 🔗 Your GitHub Pages URL (Domain)

Once enabled, Koda will be live at:
> **`https://gitofr8-source.github.io/Koda-Free/`**

Key routes that work out-of-the-box on GitHub Pages:
- **Home Website:** `https://gitofr8-source.github.io/Koda-Free/`
- **AI Workspace:** `https://gitofr8-source.github.io/Koda-Free/chat.html` *(or `/chat` via smart 404 routing)*
- **Sign In / Create Account:** `https://gitofr8-source.github.io/Koda-Free/login.html` *(with browser SHA-256 auth)*
- **Profiles & Accounts:** `https://gitofr8-source.github.io/Koda-Free/profile.html`

---

## 🚀 1-Step GitHub Pages Activation

1. Open **`https://github.com/gitofr8-source/Koda-Free/settings/pages`**
2. Under **Build and deployment → Source**, keep **`Deploy from a branch`**.
3. Under **Branch**, select **`main`** and folder **`/ (root)`**, then click **Save**.
4. Wait ~30–60 seconds for GitHub's built-in `pages-build-deployment` action to complete.
5. Visit **`https://gitofr8-source.github.io/Koda-Free/`** — your site is live worldwide with HTTPS!

---

## ✨ Optional: Connect Your Own Custom Domain

If you own a custom domain (like `koda.yourdomain.com`):
1. Go to **Settings → Pages → Custom domain** in your GitHub repository.
2. Enter your domain and click **Save**.
3. Point your domain's DNS (`CNAME` record) to `gitofr8-source.github.io`.
4. Check **Enforce HTTPS**.
